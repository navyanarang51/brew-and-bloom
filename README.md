# ☕ Brew & Bloom

A premium coffee cafe UI experience designed and developed to showcase modern frontend development and UI/UX design skills.

Brew & Bloom is a visually engaging and responsive cafe website that combines elegant design, smooth interactions, and functional frontend features to create an immersive coffee ordering experience.

The project focuses on creating a premium brand identity through thoughtful layouts, animations, responsive design, and user-friendly interactions.

---

## ✨ Features

### 🎨 Premium UI Design
- Modern coffee-themed visual identity
- Luxury dark aesthetic with warm accent colors
- Clean typography and balanced spacing
- Responsive layout for different screen sizes

### ☕ Interactive Cafe Menu
- Categorized menu sections:
  - Coffee
  - Cold Drinks
  - Cookies
  - Desserts
- Filter-based menu browsing
- Interactive product cards
- Hover effects and smooth transitions

### 🛒 Cart Functionality
- Add items to cart
- Dynamic cart counter
- Live price calculation
- Sliding cart panel experience

### ⚡ Smooth User Experience
- Scroll-based animations
- Interactive buttons
- Custom cursor effects
- Smooth navigation between sections
- Order modal interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
